# ThirdHub 官方书源（连接器）

> 零内置原则：本站不内置任何书源，以下为官方提供/适配的**可选**连接器，用户自行导入启用。

## 番茄小说（官方接口·免签名）— `fanqie-novel.js`

### 导入方式
1. 打开 ThirdHub → 分类页 → 「导入连接器」
2. 粘贴本目录 `fanqie-novel.js` 文件内容（或选择文件直接导入）
3. 启用后即可搜索「番茄小说」来源的书籍

### 实现说明
- 走番茄官网**网页接口**（搜索 / 目录 / 正文），**免签名**：浏览器环境直连即可，无需 a_bogus / msToken / Cookie 配置
- 正文接口返回明文 HTML；搜索与正文中的**字体反爬字符**（Unicode 私用区）用内置 362 项字库映射还原
- 字库来源：huixiaheyu/FanqieFetch 的 OCR 字库（字体 `dc027189e0ba4cd` 全局固定）
- 已知限制：搜索列表的书名/作者为加密字段，字库 OCR 存在少量错字（正文与详情页为明文，不受影响）；若番茄更换反爬字体，需要更新内置字库
